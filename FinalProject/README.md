# UR-Life — CSC 212 (Final Project)

> University of Rochester · CSC 212 · 2022–2025 · HTML / CSS / JS + Python

Course repository: labs, projects, and selected homework from CSC 212
(Human-Computer Interaction) at the University of Rochester. This repo holds
the course's final project.

## Course Overview
UR-Life is a campus-life web app for University of Rochester students: task
management, degree-progress tracking, a weekly course calendar, and a mailing
list manager. The project applies CSC 212's design / prototype / evaluate
HCI workflow end-to-end.

## Topics Covered
- User research, personas, and design mockups
- Front-end UI built with HTML/CSS and vanilla JavaScript
- REST endpoints with Python's built-in `http.server`
- JSON-file persistence and simple client-side data layer
- Public demo deployment via ngrok with keep-alive worker
- Iterative prototyping and usability evaluation

## What's in this Repo
- `Code/index.html`, `Code/campus-assistant.html` — login page and main dashboard
- `Code/app.js`, `Code/api.js`, `Code/users-database.js` — front-end logic
- `Code/server.py` — Python REST backend (`data/database.json` persistence)
- `Code/scripts/` — start/stop, ngrok, and keep-alive shell scripts
- `Prototype/` — design mockups and screenshots from the prototyping phase

## Tech Stack
HTML / CSS / JavaScript, Python 3 (`http.server`), Bash, ngrok
